## معرفی
نسخه اختصاصی RTL PRO برای بهبود خوانایی متن‌های فارسی و ترکیبی در مرورگرهای مبتنی بر Chromium. به جای آینه‌کردن کل رابط کاربری، بلوک‌های متنی و فیلدهای نوشتن را هدف می‌گیرد.

## قابلیت‌های پیش‌نمایش
- تشخیص هوشمند جهت متن؛ Auto / RTL / LTR.
- تنظیمات مستقل هر دامنه و ذخیره محلی.
- کنترل فونت، اندازه متن و فاصله خطوط.
- پنل فارسی با تم روشن و تاریک.
- پروفایل‌های ChatGPT، Gemini، Claude، DeepSeek، Grok، Perplexity و Copilot.
- انتخاب المان، CSS اختصاصی، پشتیبان JSON و میانبر قابل تنظیم.

## وضعیت انتشار
سورس و فایل نصب عمومی هنوز منتشر نشده‌اند. تعیین تکلیف حقوق بازنشر پروژه مرجع و تست عملی Chrome و Edge ضروری است.

## English
MD-RTL-PRO is a browser extension preview for Persian and mixed-direction text, with per-site settings, typography controls, automatic text direction and AI-site profiles. Public source distribution is pending upstream rights review and practical browser testing.

Maintainer: [mdazadeh](https://github.com/mdazadeh).
